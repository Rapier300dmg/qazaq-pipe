# Task Execution Engine

Проект для управления и выполнения цепочек асинхронных задач (тасков) на TypeScript.

## Требования

Перед началом работы убедитесь, что у вас установлены:

* **Node.js** (версия 16.x или выше)
* **npm** (поставляется вместе с Node.js) или **yarn** / **pnpm**

## Установка

1. Клонируйте репозиторий или распакуйте архив с проектом.
2. Перейдите в корневую директорию проекта:

```bash
cd project-folder
npm install
npm start
npm test
npm run dev
